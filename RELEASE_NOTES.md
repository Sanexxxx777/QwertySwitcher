Qwerty Switcher 0.11.0

Повседневные косяки по полевому логу:
• «Остров»: после починки одиночного английского слова внутри русского текста раскладка возвращается к русской на пробеле — больше не нужно чинить следующее слово или переключаться руками.
• Короткие личные токены (bsc, okx, xrp, hh): после двух исправлений двойным Shift чинятся сами по пробелу.
• Мгновенная коррекция стала точнее: «новый», «уволен», «pixel», «model», «kalshi», «clear» чинятся с четвёртой буквы, а не только по пробелу.
• Двойной Shift принимает более медленное нажатие (окно 600 мс).
• Исправлена потеря символа при двойном Shift сразу после смены раскладки.

Обновления по желанию:
• В настройках («Ещё» → «Программа») можно включить проверку обновлений раз в сутки и, отдельно, автоматическую установку. По умолчанию обе выключены. Приложение остаётся офлайн, пока вы сами не включите проверку; тогда оно запрашивает один файл с shulgin.is-a.dev и ничего о вас не отправляет.
• Обновление ставится на месте, права доступа Accessibility и Input Monitoring сохраняются.

Прочее:
• Кнопка «Собрать отчёт» в блоке «Логи» — zip с логами без набранного текста для отправки автору.
• Убраны остатки лицензии из настроек.
