# Звук в промо-ролике

## Музыка
**TunnelWave — Time** — CC0 (Public Domain Dedication).
Источник: https://archive.org/details/GT410_613 (сборник GT410, CC0 1.0 Universal).
Фрагмент 24:00–24:18, нормализован до −16 LUFS, с фейдами.
CC0 атрибуции не требует — указываем для прозрачности и чтобы не потерять источник.

## Звуковые эффекты
Библиотека Pixabay из пака HyperFrames (`media-use/audio/assets/sfx`).
Pixabay Content License: коммерческое использование разрешено, атрибуция не требуется.
Использованы: typing, click, click-soft, whoosh-short, impact-bass-1, impact-bass-2, key-press.

## Замер финального микса
- интегральная громкость −18.7 LUFS (норма для сайта −16…−20)
- динамический диапазон 7.2 LU
- истинный пик −3.8 dBFS, перегруза нет
